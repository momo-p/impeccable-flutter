# Fonts

Both faces are under the SIL Open Font License, so they are redistributable and
the example runs without anyone sourcing files first. Licence text sits beside
each one.

- `Fraunces.ttf` for display, from [undercasetype/Fraunces](https://github.com/undercasetype/Fraunces)
- `Karla.ttf` for body and labels, from [googlefonts/karla](https://github.com/googlefonts/karla)

Neither is on the overused list the detector checks, which is the point. A real
project picks its own; these are here so the example is runnable.
