# Posters

Real film posters, all in the public domain, from Wikimedia Commons. An example
that claims to care about design should not illustrate itself with grey boxes.

| File | Film | Source |
|---|---|---|
| `the-general.png` | The General (1926) | [Commons](https://commons.wikimedia.org/wiki/File:The_General_(1926)_-_Movie_Poster_2.png) |
| `his-girl-friday.jpg` | His Girl Friday (1940) | [Commons](https://commons.wikimedia.org/wiki/File:His_Girl_Friday_(1940_poster).jpg) |
| `night-of-the-living-dead.jpg` | Night of the Living Dead (1968) | [Commons](https://commons.wikimedia.org/wiki/File:Night_Of_The_Living_Dead_(1968)_-_Poster.jpg) |

Each is tagged public domain on Commons: the first two by age, the third
because it was released without a copyright notice. They are downscaled
thumbnails, unmodified otherwise.

`library_after.dart` handles a failed load with `errorBuilder`, so swapping
these for your own, or deleting them, both render.
